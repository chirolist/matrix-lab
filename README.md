# Matrix Lab

観測データをベクトルにし、行列と確率モデルでカテゴリを推定する実験用 Web アプリです。最初の題材は、パチスロ「ジャグラー」のボーナス実績から設定1〜6の推定確率を計算するサンプルです。

推定はブラウザ内で完結します。結果は統計モデル上の値であり、実機の設定を保証しません。

## 開発

```bash
npm install
npm run dev
```

ブラウザで http://localhost:3000 を開きます。

```bash
npm test
npm run lint
npm run build
```

## 設定値の更新

`src/data/jugler-settings.ts` の分母と機械割を、対象機種の公式情報などに合わせて更新します。合成確率の掲載値は表示と検証用で、推定計算には使いません。
